Bring your agent

Talk to Claude Code right in the Agents panel, or use Claude Code, Codex and other agents in the built-in terminal. Each tool uses its own setup and authentication.

Open the Agents panel with Ctrl + Shift + A (Cmd + Shift + A on macOS) to follow sessions associated with your project.

Talk to Claude Code

rhun runs the claude you have installed, with whatever it is signed in with. Conversations use your plan’s limits, as they do in the terminal, and rhun never handles your credentials. To sign in, run claude auth login in the terminal, or click Sign In when the panel says Claude Code is not signed in.

Click + Claude Code to start a conversation, or open one from the list to continue it. Enter sends and Shift + Enter starts a new line. Stop or Esc interrupts a reply.

When Claude asks to use a tool, a card shows Yes and No. Questions and plans to approve show as cards too. Click an answer, or with the panel focused (not the prompt box) press 1 to 9 or use the arrow keys and Enter.

Only while you use it

Claude Code starts when you begin to type and stops after ten idle minutes; your next prompt starts it again. Change that with Stop idle agents after in Settings › Agents.

Follow your sessions

The panel brings Claude Code, Codex, Grok Build and OpenCode sessions into one list. Sessions update in the background while you work, without needing a manual refresh.

The first view shows the 50 most recent sessions across providers and worktrees. Use Load more to bring in the next 50.

Replies are drawn as Markdown, with headings, lists, tables and code. A link to a file opens it in the editor at its line.

The panel has its own text size. Focus it and use Ctrl + + and Ctrl + - (Cmd on macOS), run Agents: Increase Font Size from the command palette, or set Font size in Settings › Agents.

Out of the way when you are done

Background refresh pauses when the Agents panel is hidden.

Across worktrees

Sessions from the project’s Git worktrees appear alongside the main checkout. Provider labels and worktree badges help you tell them apart.

rhun remembers verified worktree paths, so past sessions can remain visible even after a worktree is removed.

Review the changes

When an agent changes a file on disk, rhun reloads it. If you have unsaved edits in that file, your buffer stays intact and a warning lets you choose what to keep.

Use Git diffs to inspect the changes, then stage and commit the parts you want.
