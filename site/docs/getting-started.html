Install rhun

Choose your platform. rhun runs on Linux x86-64, Apple silicon Macs, and Windows x64 (Windows 10 version 1809 or later).

Linux & macOS

Paste this into your terminal. The installer checks the download and adds the rhun command. No root access needed.

curl -fsSL https://github.com/vshvedov/rhun/releases/latest/download/install.sh | sh

Windows

Download the installer in PowerShell:

$rhunInstaller = Join-Path $env:TEMP ('rhun-install-' + [guid]::NewGuid() + '.ps1')
[Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12
Invoke-WebRequest -UseBasicParsing -Uri 'https://github.com/vshvedov/rhun/releases/latest/download/install.ps1' -OutFile $rhunInstaller -ErrorAction Stop

After the download succeeds, you can inspect the installer source. Run it in the same PowerShell window:

powershell -NoProfile -ExecutionPolicy RemoteSigned -File $rhunInstaller

The installer checks the release archive's SHA-256, installs for your user, and adds a Start menu shortcut and the rhun terminal command. Open a new terminal after installation.

Prefer a download? Get an archive from Releases. On Windows, extract the ZIP and open rhun.exe. Keep rhun.com beside it for terminal use.

Open a project

Open rhun from your app launcher, or start in the folder you are working on:

rhun .

Use Ctrl + Shift + O to choose a folder, or Ctrl + O for a single file. A project remembers its tabs and layout when you return.

On a Mac

Most shortcuts use Cmd in place of Ctrl, and Option for Alt. Keep Control for Tab, H, and the terminal shortcut `.

For a quick edit, run rhun notes.txt: the window shows just the file, without the explorer or the agents panel, until you bring them back.

Want a blank window? Run rhun --empty. For tools that need to wait until you finish editing, use rhun --wait file.txt.

Links like rhun://file/home/me/app/main.rs:42 open in rhun from a browser or a chat, at that line, the way vscode://file/ links open VS Code.

Find your way

The command palette is the place to start when you do not remember a shortcut. Open it with Ctrl + Shift + P or F1, then type what you want to do.

Ctrl + P
Find a file by name.
Ctrl + B
Show or hide the file explorer.
Ctrl + ,
Open Settings.

The project menu lets you return to recent folders or open a new window. Right-click in the explorer to create files and folders.

Stay up to date

Release builds check for updates in the background. When the status bar offers Update to X, click to download, then choose Restart to update. rhun asks about unsaved files and reopens your project.

You can also run Check for Updates from the command palette. Turn off automatic checks in Settings if you prefer to check yourself.
