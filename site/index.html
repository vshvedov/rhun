Install

WindowsLinuxmacOS

Download a release
Terminal install · Linux & macOS>_
$curl -fsSL https://github.com/vshvedov/rhun/releases/latest/download/install.sh | sh
Terminal install · Windows PowerShell>_

1. Download the installer

>$rhunInstaller = Join-Path $env:TEMP ('rhun-install-' + [guid]::NewGuid() + '.ps1') [Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12 Invoke-WebRequest -UseBasicParsing -Uri 'https://github.com/vshvedov/rhun/releases/latest/download/install.ps1' -OutFile $rhunInstaller -ErrorAction Stop

After the download succeeds, you can inspect the installer source.

2. Run it in the same PowerShell window

>powershell -NoProfile -ExecutionPolicy RemoteSigned -File $rhunInstaller

Checks the release archive's SHA-256, installs for your user, and adds a Start menu shortcut and the rhun terminal command.
